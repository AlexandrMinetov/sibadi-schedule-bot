# СибАДИ — БИ-22Э1

Предварительная версия. API взят из публикации СибАДИ 2023 года; актуальный ответ не проверен. Не включайте автоматическую рассылку до проверки diagnose. Для этого временно удалите блок schedule из YAML перед загрузкой, верните после проверки.

1. Создайте бота через @BotFather /newbot. Добавьте в группу, разрешите отправку сообщений.
2. Создайте репозиторий. Загрузите bot.py и .github/workflows/schedule.yml с сохранением путей. Через веб-интерфейс workflow можно создать отдельным файлом с полным путём.
3. Settings → Secrets and variables → Actions → New repository secret → BOT_TOKEN.
4. Напишите в группе /chatid@имя_бота. В Actions → Schedule bot → Run workflow выберите chat_id. Бот ответит ID группы. Сохраните его в секрете CHAT_ID.
5. Run workflow → test. Проверьте сообщение.
6. Run workflow → diagnose. Проверьте структуру JSON и пришлите её разработчику для сверки парсера. Логи публичного репозитория публичны; не публикуйте персональные или закрытые поля. Если сомневаетесь, используйте приватный репозиторий для диагностики.
7. После проверки включите schedule. Запуск в 07,22,37,52 минуты каждого часа; вечерняя рассылка при первом успешном запуске после 20:00 Омска. Возможны задержки GitHub.

Состояние хранится в state.json в репозитории (только расписание и флаг публикации). Не содержит токен или chat ID. В публичном репозитории это публичные данные. Приватный репозиторий имеет лимит минут. При сбое между отправкой и сохранением возможен повтор сообщения. Пустой ответ API не интерпретируется как отмена. Команды расписания в этой версии отсутствуют.
