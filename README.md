# СибАДИ — БИ-22Э1

Telegram-бот расписания группы 14992. Получает данные из официального API СибАДИ.

## Команды

| Команда | Действие |
|---|---|
| /today | Расписание на сегодня |
| /tomorrow | Расписание на завтра |
| /week | Расписание на текущую календарную неделю (понедельник — воскресенье) |
| /help | Список команд |

Команды принимаются только в настроенной теме. В группе можно использовать форму `/today@sibadi_bi22e1_bot`. Обычные сообщения игнорируются, не сохраняются и не анализируются.

## Развёртывание

В GitHub Secrets задайте BOT_TOKEN, CHAT_ID и THREAD_ID. Включите GitHub Actions и разрешите запись contents для сохранения состояния. Боту нужны права отправки сообщений; для автоматического закрепления предоставьте право закреплять сообщения. Ошибка закрепления не мешает рассылке.

Проверка команд: Actions → Schedule bot → Run workflow → poll. Меню команд регистрируется автоматически для группы. Команды обрабатываются примерно раз в 5 минут, расписание проверяется раз в 15 минут. Вечерняя рассылка — после 20:00 по Омску (первый плановый запуск в 20:02). GitHub может задерживать или пропускать запуски.

Режимы: preview (без отправки), poll (команды), test (проверка Telegram), diagnose (проверка источника), publish_today (рассылка на сегодня с защитой от повтора).

Состояние в state.json содержит расписание, признаки публикации, технические ID сообщений самого бота и смещение Telegram updates. В публичном репозитории оно доступно для чтения. Токены, ID группы, тексты пользователей и сведения об отправителях не сохраняются. При сбое между отправкой и сохранением состояния возможен повтор. Пустой или некорректный ответ API не трактуется как отмена занятий. Автоматические сообщения закрепляются, старое закреплённое сообщение самого бота открепляется. Ответы на команды не закрепляются.
